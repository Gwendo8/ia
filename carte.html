L'équipe6

Les agents : des Claude spécialisés, chacun dans son métier.

  • AuditeurPasse le projet en revue, vérifie chaque problème, écrit AUDIT.md et les tests de bout en bout, sans corriger le code des autres.

    Auditeur (sécurité, cohérence, qualité, tests, performance, accessibilité). Passe le projet en revue, vérifie chaque problème, écrit AUDIT.md et les tests de bout en bout, sans corriger le code des autres.

    Opus · le plus fortagent ia-kit:auditeur/ia-kit:auditeur
  • BackDéfinit le contrat de l'API en dialogue avec l'utilisateur, puis code les routes, la validation, la logique métier, l'accès aux données et les tests.

    Spécialiste API (Node.js + Express + Sequelize). Définit le contrat de l'API en dialogue avec l'utilisateur, puis code les routes, la validation, la logique métier, l'accès aux données et les tests.

    Sonnet · équilibréagent ia-kit:back/ia-kit:back
  • BDDConçoit le schéma en dialogue avec l'utilisateur, puis crée la base, les migrations et les modèles.

    Spécialiste base de données (PostgreSQL + Sequelize). Conçoit le schéma en dialogue avec l'utilisateur, puis crée la base, les migrations et les modèles.

    Opus · le plus fortagent ia-kit:bdd/ia-kit:bdd
  • ChercheurTrouve des fichiers, collecte et extrait des informations dans beaucoup de fichiers, puis rend une liste de résultats avec chemins et numéros de ligne.

    Chercheur en lecture seule, sur Haiku pour économiser le quota. Trouve des fichiers, collecte et extrait des informations dans beaucoup de fichiers, puis rend une liste de résultats avec chemins et numéros de ligne.

    Haiku · léger et économeagent ia-kit:chercheur
  • DesignRecherche l'inspiration ciblée sur le projet, propose trois variantes en dialogue avec l'utilisateur, puis écrit DESIGN.md et les maquettes Figma.

    Spécialiste design (UI, couleurs, typographie, animations). Recherche l'inspiration ciblée sur le projet, propose trois variantes en dialogue avec l'utilisateur, puis écrit DESIGN.md et les maquettes Figma.

    Opus · le plus fortagent ia-kit:design/ia-kit:design
  • FrontPrésente son plan en dialogue avec l'utilisateur, puis code les écrans d'après DESIGN.md, les maquettes Figma et API.md, avec tests et vérification visuelle.

    Spécialiste front-end (React + Vite + Tailwind). Présente son plan en dialogue avec l'utilisateur, puis code les écrans d'après DESIGN.md, les maquettes Figma et API.md, avec tests et vérification visuelle.

    Sonnet · équilibréagent ia-kit:front/ia-kit:front

Gardiens7

Ils travaillent tout seuls, au bon moment, sans qu’on le demande.

  • À chaque message que tu envoiesRepère les messages où l'utilisatrice corrige Claude.

    Script : reperage-erreurs.mjs.

    hookUserPromptSubmit
  • Avant chaque outil utilisé par ClaudeGarde-fou « même modèle ».

    Script : meme-modele.mjs.

    hookPreToolUse
  • Après chaque outil utilisé par ClaudeSurveille le contexte des agents back, front et auditeur.

    Script : surveillance-contexte.mjs.

    hookPostToolUse
  • Au début de chaque conversationRappelle le ménage mensuel de la mémoire.

    Script : rappel-menage.mjs.

    hookSessionStart
  • Au début de chaque conversationSignale à Claude ce qui a changé depuis la dernière mise à jour de PROJET.md.

    Script : projet-sync.sh (mode debut).

    hookSessionStart
  • À la fin de chaque réponseSi du code a changé sans que PROJET.md suive, empêche Claude de s'arrêter et lui demande la mise à jour.

    Script : projet-sync.sh (mode fin).

    hookStop
  • Skill erreursNote une erreur de Claude dans le journal global des erreurs, et la passe en règle permanente quand elle revient.

    Il se déclenche tout seul quand la situation le demande.

    skill
